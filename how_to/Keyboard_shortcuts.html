    Keyboard shortcuts

    This page lists every keyboard shortcut available in the AgnosPCB inspection software, together with the mouse actions used to review the detections.

    Main window

    Key Action
    R Take a REFERENCE image (opens the live preview).
    S Start an inspection (capture the UUI).
    Tab Switch the view mode of the main workspace (REFERENCE / UUI).
    Page Up Switch to the TOP side of the loaded REFERENCE (double-sided REFERENCES only).
    Page Down Switch to the BOTTOM side of the loaded REFERENCE (double-sided REFERENCES only).
    F1 … F8 Load the REFERENCE stored in that slot of the Reference mosaic.
    Right Next detection (or next row of the detections list with Analysis preference = LIST).
    Left Previous detection (or previous row of the detections list with Analysis preference = LIST).
    Up Report the detection as an actual error (opens the reporting window). On an area with no detection, reports an error not detected by the software.
    Down Report the detection as a false positive.
    1 Sensitivity: Normal.
    2 Sensitivity: High.
    3 Sensitivity: Very High.
    Space Turn the platform lighting on / off.
    F Show / hide the error report overlay.
    Enter Process an image loaded manually.

    Note

    With user access control enabled, the Up and Down keys require the Classify detected faults permission.

    Reviewing detections with the mouse

    Mouse action (on the image) Action
    Left click on a detection Report it as an actual error (same as Up). On a detection already reported as an error, asks for confirmation before undoing it.
    Right click on a detection Report it as a false positive (same as Down).
    Left click on an empty area Report an error not detected by the software.
    Keep the pointer still on a detection for about 1 second Mark it as seen.
    Right click outside a detection Change the shape of the zoom lens.
    Shift + right click Change the shape of the zoom lens, also on top of a detection.
    Mouse wheel Change the zoom level.

    The mouse actions of the detections list (thumbnails, buttons, scrolling) are described in Detections list.

    Reporting window

    Key Action
    Up / Down Move through the options of the drop-down list.
    Enter Confirm.
    Esc Cancel.

    Other windows

    Window Key Action
    Live preview (REFERENCE / UUI) Enter Confirm / OK.
    Live preview (REFERENCE / UUI) Esc Cancel.
    Reference mosaic F1 … F8 Load the REFERENCE of that slot.
    REFERENCE search list Esc Close the window without loading a REFERENCE.
    Login Enter Log in.
    Settings menu Enter OK (save and close).
    Settings menu Esc Close.
