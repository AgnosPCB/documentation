# Allineamento manuale delle immagini

Quando le immagini di RIFERIMENTO e UUI devono essere allineate con maggiore precisione di quanto consenta l'allineamento automatico, il software AgnosPCB include uno strumento di allineamento manuale che migliora l'accuratezza dell'ispezione.

## 1. Abilitare l'allineamento manuale

!!! info "Nota"
    Questa funzione è disponibile solo per le ispezioni di **immagini 1x1**.

Durante l'acquisizione di una nuova immagine UUI, attivate l'allineamento manuale dal menu Impostazioni.

![Opzione di allineamento manuale](../assets/v7/manual_align/1-manual-alignment-option.png){.center}

Successivamente, durante l'acquisizione dell'immagine UUI, attivate l'opzione di allineamento manuale.

![Opzione di allineamento manuale](../assets/v7/manual_align/manual-aling-button.png){.center}

## 2. Allineare le immagini

Subito dopo l'acquisizione dell'immagine UUI, compare la finestra di allineamento manuale che mostra le immagini di RIFERIMENTO e UUI.

![Finestra di allineamento manuale](../assets/v7/manual_align/2-MA-zoom.png){.center}

Contrassegnate ora tre punti di riferimento nell'immagine di RIFERIMENTO.

!!! warning "Importante"
    Scegliete punti facili da riprodurre da un pannello all'altro (fori, pad, ecc.), vicini agli angoli del pannello e il più distanti possibile tra loro.

!!! note "Nota"
    Utilizzate la rotellina del mouse per ingrandire l'immagine e contrassegnare i punti con maggiore precisione.

![Contrassegno del primo punto](../assets/v7/manual_align/3-MA-P1.png){.center}

![Contrassegno del secondo punto](../assets/v7/manual_align/4-MA-P2.png){.center}

![Contrassegno del terzo punto](../assets/v7/manual_align/5-MA-P3.png){.center}

Una volta definiti i tre punti di allineamento nell'immagine di RIFERIMENTO, contrassegnate **gli stessi tre punti** nell'immagine UUI.

!!! warning "Importante"
    Per garantire un allineamento corretto, posizionate ogni punto esattamente sullo stesso dettaglio del pannello presente nell'immagine di RIFERIMENTO.

![Contrassegno del primo punto](../assets/v7/manual_align/6-MA-UUI-P1.png){.center}

![Contrassegno del secondo punto](../assets/v7/manual_align/7-MA-UUI-P2.png){.center}

![Contrassegno del terzo punto](../assets/v7/manual_align/8-MA-UUI-P3.png){.center}

Una volta posizionati tutti i punti di allineamento, premete il pulsante **ALIGN** per avviare il processo. Il software allinea entrambe le immagini e poi esegue l'ispezione.

![Immagini allineate](../assets/v7/manual_align/MA-final.png){.center}
