# Workspace icons

Workspace icons provide quick access to useful features.

![Workspace Icons](../assets/v7/workspace-icons.png){width=600 .center}

## Show/hide crosses

![Crosses icon](../assets/v7/workspace-icons-1.png){width=200 .center}

This option shows or hides the crosshairs and error numbers in the main workspace area, for greater visibility of the UUI image.

## Auto process

![Autoprocess icon](../assets/v7/workspace-icons-2.png){width=200 .center}

Enables or disables automatic processing after the UUI image is taken. When it is active, the inspection starts by itself as soon as the image has been captured — see the [inspection workflow](./Inspection_workflow.md).


## Error mask color

![Mask color icon](../assets/v7/workspace-icons-3.png){width=200 .center}

Changes the error mask color to one that contrasts better with the PCBA color. The opacity of the mask can also be changed by pressing **CTRL** + **mouse wheel up/down** while the pointer is over the icon.

The default color can be set in the [settings menu](./Settings_menu.md#mask-color).
